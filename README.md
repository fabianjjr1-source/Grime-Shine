# Orlando Grime & Shine Website

A responsive, static website for gutter cleaning and Christmas light installation in Orlando, Florida.

## Booking form
All quote buttons open your Jotform: https://form.jotform.com/263200703417042
Bookings are requests, not confirmed appointments.

## Publish with GitHub Pages
1. Create a new public GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, `logo.png`, and `hero.png` to the repository root (not inside another folder).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then **main** and **/(root)**, and save.
5. GitHub will provide a public website URL once deployment finishes.

## Publish with Netlify
1. Extract the ZIP.
2. Visit https://app.netlify.com/drop and drag the extracted `orlando-grime-shine` folder onto the page.
3. Netlify will provide a temporary live URL. You can later connect a custom domain.

## Customization
- Colors: edit CSS variables at the top of `styles.css`.
- Service descriptions: edit `index.html`.
- Booking URL: replace `https://form.jotform.com/263200703417042` in `index.html` if your form changes.
- Images: replace `logo.png` and `hero.png` with your preferred final branding images, keeping the same filenames.

Before publishing, confirm that all service descriptions reflect what you actually offer and that Jotform email notifications are enabled.
